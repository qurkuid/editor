실제 3종 도면에서 존은 생성됐지만 일부는 물리 경계가 불완전하거나 여러 의미 공간이 하나의 벽 루프 안에 있어 검토가 필요합니다. 열린 존을 닫혔다고 처리하거나 원본에 없는 벽을 만들지 않았습니다.

화명 177B 원본 도면

빠른 연결 후보는 우측 하부 안방의 아래 경계 끝, 하부 발코니와 만나는 약 20.3mm 틈입니다. 원본 그림의 약 (780,574) 픽셀 위치에 대응합니다. 대상 벽에 창문이 호스팅돼 있어 연결 시 위치 보존도 검사합니다.

화명 177B 브라우저 실행 결과

실제 검색 → 177B 도면 선택 → 자동 모델 v13 생성 → 2D → Zones → 20mm 경계 연결을 실행했습니다. 저장된 모델에서 닫힌 공간 7→8, 경계 이슈 10→8, 빠른 연결 후보 1→0을 확인했습니다. 벽 61개·문 11개·창 10개·존 14개가 유지되며, 새 물리 벽은 생성되지 않았습니다.

다시 열어도 연결된 끝점과 공간 수가 유지됩니다. 닫힘 확인 존은 5개, 검토 필요 존은 9개입니다. 검토 대상 이름: 발코니 3개, 안방 3개, 욕실, 거실, 현관.
