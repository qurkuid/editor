미실행·미검증

GitHub Actions: 기본 브랜치 main과 배포 브랜치 모두 워크플로 파일이 존재합니다. main의 기존 push 조건은 main만 허용했고, 배포 커밋에서는 deploy/floorplan도 추가했습니다. 저장소 Actions 설정은 enabled=true지만 등록 워크플로 조회는 여전히 total_count=0이며 이번 커밋의 원격 실행 기록은 없습니다. 남은 등록·실행 원인은 조회 결과만으로 확정하지 못했습니다. 접근권한이나 보안 설정은 변경하지 않았습니다.

운영 GLB 클릭: Chrome 2D/3D 및 별도 in-app browser의 실제 3D 렌더 후 버튼을 실행했습니다. 공식 download 이벤트는 Chrome에서 30초, in-app browser에서 10초 내 확인되지 않았습니다. Chrome의 최근 Downloads 폴더에서도 GLB를 찾지 못했습니다. in-app browser에서는 GLTFExporter 실행 경고가 관찰됐고 오류 로그는 없었습니다. 이는 exporter 호출 증거이며 운영 파일 생성 완료나 다운로드 전달 완료의 증거는 아닙니다. 후속 점검에서는 같은 대기를 반복하지 않았습니다.

chrome://downloads 확인은 브라우저 URL 정책상 차단되어 우회하지 않았습니다. 실제 SketchUp 가져오기, 새 릴리스에서 각도 스냅의 마우스 체감, 8개 도면 전체의 UI 자동모델링·문창문 분류·원본 대비 공간 일치, 3D 벽 이동/Undo와 모바일 전체 편집은 이번에 다시 수작업 검수하지 않았습니다. 관련 전체 소스 회귀 테스트와 8개 추출 API 검증만 새로 수행했습니다.
