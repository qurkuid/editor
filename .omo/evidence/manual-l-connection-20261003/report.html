최종 동작

가로→세로와 세로→가로를 선택할 수 있습니다. 두 연결벽은 출발 벽의 물리 두께·높이·재질을 이어받습니다. 기존 벽과 문·창을 이동하지 않으며 한 번의 실행 취소로 전체 장면을 복원합니다. 벽면 중간 T 접점도 지원합니다.

기존 직선 모드는 지지선 교점으로 연장하는 동작을 유지합니다. ㄱ자 모드의 두 변은 각각 1cm 이상이어야 하며 같은 층·지지면의 직선 벽 사이에서 사용합니다. 벽 겹침과 역주행을 거부합니다. 주변 곡선벽과 제3벽의 근접 충돌은 보수적으로 거부할 수 있습니다.

검증

  • 격리 릴리스: 253개 테스트 / 15개 파일 통과. core·nodes·MCP 빌드, 앱 타입 검사, 정적 검사 9개 파일, 프로덕션 빌드 통과. UI는 타입 검사·소스 검수·브라우저 검증.
  • 실제 Chrome / 로컬 프로덕션 빌드 3018: 양방향 미리보기, 안정된 id, 미리보기 중 전체 graph 불변 확인.
  • 적용: 벽 2개 추가. 기존 출발/대상 벽·문·창 JSON 정확히 보존.
  • Undo는 변경 전 graph와, Redo와 새로고침은 적용 후 graph와 정확히 일치.
  • 벽면 클릭의 T 접점 적용, 겹침 방향 거부 후 방향 전환 복구, Esc 취소, 뷰 전환 모드 정리 확인. 3D 연결벽 표시 확인.
  • 운영 서버 동일 테스트 253개·타입·빌드 통과. PM2 online, 재시작 0, 공용 /apt HTTP 200. 운영 브라우저의 build id와 실제 로드된 ㄱ자 제어 JS의 SHA256이 원격 빌드와 일치.

운영 저장 장면에는 연결을 적용하지 않았습니다. 실제 적용·Undo는 격리 QA 복제 장면에서 검증했습니다. 기존 3002 서버는 응답하지 않아 별도 3018 검증 서버를 사용했습니다.

경고: 기존 THREE.Clock 및 viewer readiness timeout 경고가 있으나 최종 3D 렌더링은 확인했습니다. 콘솔 오류 0. 기존 middleware 빌드 경고 유지. CI 워크플로 실행 대신 로컬·운영 서버 명령 검증을 수행했습니다.
